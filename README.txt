OSCECORE v1.0 — 300 ORIGINAL MEDICAL EDUCATION CASES

Quickest start: open OSCECore_Standalone.html in a modern browser. No hosting, installation, login or internet needed.

For GitHub Pages: unzip OSCECore_PWA.zip to the root of a GitHub Pages repository and enable Pages from main / root. The PWA caches core files after the first hosted load and can be installed from a compatible browser.

Controls: on the dashboard select Rapid Diagnosis, Full Encounter or Mock Circuit. The builder filters systems, difficulty and answer method. The quiz interface intentionally hides system/specialty and final diagnosis until you answer. After submission, detailed feedback appears immediately and can be expanded or collapsed. The full encounter uses finite scripted patient answers and keyword-based typed question routing (NOT a live AI patient).

Progress: records and preferences save in your browser's localStorage. Use Settings to export a progress backup (.json) and import it to a different browser/device. This app does not automatically sync.

Case distribution: MSK 40; Cardio 40; Pulm 42; Renal 40; GI 46; Neuro 43; Endo/Repro 49. Total 300.

Quality note: Original educational vignettes and clinician-style teaching summaries; not individually externally clinically validated. The automated free-text checker is limited; a self-correction option covers acceptable synonyms. The OSCE checklist measures addressed domains, not quality of free-text responses and is not an official score. Follow current local clinical guidelines and teaching resources.

Primary learning references: https://www.merckmanuals.com/professional/health-topics
